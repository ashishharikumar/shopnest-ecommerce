# ShopNest E-commerce Website

Responsive e-commerce major project built with HTML, CSS, JavaScript, Node.js, Express, and MongoDB.

## Run locally

1. Install and start MongoDB locally, or create a free MongoDB Atlas cluster.
2. Copy `.env.example` to `.env` and set `MONGODB_URI` (and a strong `JWT_SECRET`).
3. Run `npm start`.
4. Open `http://localhost:5000`.

## Included modules

- Customer registration/login, product browsing, product details, cart, COD checkout, notification, order history, and logout.
- Admin login, dashboard totals, product creation/editing/deletion, customer list, order list, and order-status updates.
